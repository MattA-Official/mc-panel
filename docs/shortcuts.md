# Keyboard shortcuts

Press **?** on any page to see these in the panel. They never fire while you're typing in a field, the console or an editor, and they never replace the browser's own Ctrl (⌘ on a Mac) keys.

## Anywhere

| Keys     | Does                                                                 |
| -------- | -------------------------------------------------------------------- |
| Ctrl + K | Search servers, pages and actions                                    |
| ?        | List the shortcuts                                                   |
| /        | Focus the page's search, or the console's command line               |
| Ctrl + S | Save on Settings or in the file editor; on YAML, review your changes |
| Escape   | Close the open dialog, menu or editor                                |

## Go to (press G, then a letter)

| Keys | Goes to  |
| ---- | -------- |
| G S  | Servers  |
| G A  | Activity |
| G Y  | System   |

On a server page these go to a part of that server:

| Keys           | Goes to                                     |
| -------------- | ------------------------------------------- |
| G C            | Console                                     |
| G L, or just L | Logs                                        |
| G P            | Players                                     |
| G B            | Backups (on World)                          |
| G N            | Content                                     |
| G W            | World                                       |
| G F            | Files                                       |
| G T            | Settings                                    |
| G M            | YAML                                        |
| [ and ]        | The same tab on the previous or next server |

## Lists and cards

On the server cards and the rows of Files, Backups and Content:

| Keys                | Does                                                               |
| ------------------- | ------------------------------------------------------------------ |
| J and K, or ↓ and ↑ | Move to the next or previous row                                   |
| Enter               | Open the row (a file opens in the editor, a card opens its server) |
| . or Shift + F10    | Open the row's menu, as a right-click would                        |
| Shift + Delete      | Delete the row, with the usual confirm                             |

Starting, restarting and stopping a server have no single key on purpose, so a stray key press can't stop it. Use the buttons, the row's menu or Ctrl + K.

## Turning them off

Single-key shortcuts (the letters, **?**, **/**, **[** and **]**) can be turned off for one browser under **This browser** on **Your account**, for example if you use voice control or a screen reader that sends keys. Ctrl + K and Ctrl + S keep working.
